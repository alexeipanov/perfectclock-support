# Perfect Clock

**Perfect Clock** is a world clock timeline for tracking time zones, working hours, events, and overlapping free time across different locations.

Website: <https://perfectclock.cc>

Chrome extension: [Perfect Clock on Chrome Web Store](https://chromewebstore.google.com/detail/oecbfdgpeigoogoehhkffgpnmiepeefe)

## Public calendars

Ready-made event calendars shown on the timeline in your time zone. Free, no sign-up.

**Markets**

* [Big Four Stock Exchanges](https://perfectclock.cc/big-four-stock-exchanges) — NYSE, NASDAQ, Shanghai and Tokyo trading hours with holidays and early closes
* [Forex Sessions & News](https://perfectclock.cc/forex) — London, New York, Tokyo and Sydney sessions plus high-impact news
* [Crypto Expiries & Macro](https://perfectclock.cc/crypto) — Deribit and CME BTC/ETH expiries and US macro news

**Sports with Polymarket odds**

* [F1 & Polymarket](https://perfectclock.cc/f1-polymarket) — every practice, sprint, qualifying and race
* [World Sports & Polymarket](https://perfectclock.cc/sports-polymarket) — Champions League, UFC, tennis finals and big boxing fights
* [NBA & Polymarket](https://perfectclock.cc/nba-polymarket) — every NBA game of the season
* [NHL & Polymarket](https://perfectclock.cc/nhl-polymarket) — every NHL game of the season
* [NASCAR & Polymarket](https://perfectclock.cc/nascar-polymarket) — Cup, O'Reilly and Truck Series races

**Sports**

* [MotoGP](https://perfectclock.cc/motogp) — MotoGP sessions plus Moto2 and Moto3 races
* [Winter World Cup](https://perfectclock.cc/winter-world-cup) — skiing, biathlon, ski jumping, sliding and skating start times
* [Endurance](https://perfectclock.cc/endurance) — World Marathon Majors, IRONMAN World Championship and cycling classics

**Space**

* [Rocket Launches](https://perfectclock.cc/rocket-launches) — upcoming SpaceX, Rocket Lab, ISRO and JAXA launches

## Support

If you have found a bug or have a feature request, please [open an issue](../../issues/new/choose).

Before opening an issue, check the existing issues to see if the problem has already been reported.

When reporting a bug, please include:

* what you expected to happen;
* what happened instead;
* steps to reproduce the problem;
* browser and operating system;
* screenshots or other relevant information, if applicable.

Please do not include passwords, access tokens, private calendar information, or other sensitive data in issues.

## Feature requests

Feature requests are welcome. Describe the problem you are trying to solve and, if possible, provide an example of how you would use the proposed feature.

## About this repository

This repository is used for public support, issue tracking, and feedback for Perfect Clock.

The application source code is maintained in a private repository.
