
# Perfect Clock

**Perfect Clock** is a world clock timeline for tracking time zones, working hours, events, and overlapping free time across different locations.

Website: <https://perfectclock.cc>

Chrome extension: [Perfect Clock on Chrome Web Store](https://chromewebstore.google.com/detail/oecbfdgpeigoogoehhkffgpnmiepeefe)

## Support

If you have found a bug or have a feature request, please [open an issue](../../issues/new/choose).

Before opening an issue, check the existing issues to see if the problem has already been reported.

When reporting a bug, please include:

* what you expected to happen;
* what happened instead;
* steps to reproduce the problem;
* browser and operating system;
* screenshots or other relevant information, if applicable.

Please do not include passwords, access tokens, private calendar information, or other sensitive data in issues.

## Feature requests

Feature requests are welcome. Describe the problem you are trying to solve and, if possible, provide an example of how you would use the proposed feature.

## About this repository

This repository is used for public support, issue tracking, and feedback for Perfect Clock.

The application source code is maintained in a private repository.
